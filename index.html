QTakeSync

QTakeSync is a macOS app for video-assist crews on film sets. It runs on the Macs that record with QTAKE and:

  • protects QTAKE project folders on each Mac,
  • collects clips from the other Macs on the set onto the main Mac,
  • uploads clips to the crew's own cloud storage (Google Drive or Yandex Disk).

Google Drive

When a user connects Google Drive, QTakeSync asks only for the drive.file permission: it can see and change only the files and folders it creates itself, in a folder called "QTake Uploads". It cannot read any other file in the user's Drive.

QTakeSync is distributed privately to the crews that use it. It is not sold or offered to the public.
